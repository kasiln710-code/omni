API 接口文档

OmniConnect 提供企业级 RESTful API，支持 SMS、WhatsApp、语音、邮件等多通道统一调用。

🔐

认证方式

支持 API Key + Secret 签名认证与 OAuth 2.0 两种方式。所有请求通过 HTTPS 加密传输。

POST
/v1/sms/send

发送单条/批量发送短信，支持模板变量、定时发送、状态回调。

POST
/v1/whatsapp/send

发送文本、图片、文档、模板消息，支持交互式按钮与快速回复。

POST
/v1/voice/call

发起 AI 语音外呼，支持 TTS 文本转语音、多轮对话流程配置。

POST
/v1/email/send

发送 HTML/纯文本邮件，支持模板变量、附件、批量发送。
